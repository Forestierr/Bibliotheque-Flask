## Signalement d'une vulnérabilité (Français)

La sécurité et la confidentialité des données des enseignants et de leurs élèves sont notre priorité.

Si vous découvrez une faille de sécurité ou une vulnérabilité dans cette application :
1. **Ne créez PAS d'issue GitHub publique** pour décrire la vulnérabilité.
2. Envoyez un signalement détaillé par e-mail à : **livresenclasse@gmail.com**
3. Veuillez inclure :
   - La nature de la faille (ex. injection, contournement d'authentification, fuite de données),
   - Les étapes ou le script permettant de reproduire le problème,
   - L'impact potentiel estimé.

Nous nous engageons à accuser réception de votre rapport sous 48 heures ouvrées et à déployer un correctif dans les plus brefs délais.

---

## Reporting a Vulnerability (English)

The security and privacy of teachers' and students' data is our top priority.

If you discover a security vulnerability in this application:
1. **Do NOT open a public GitHub issue** describing the vulnerability.
2. Send a detailed report via email to: **livresenclasse@gmail.com**
3. Please provide:
   - Type of vulnerability (e.g. injection, auth bypass, data leakage),
   - Steps or proof-of-concept script to reproduce,
   - Potential impact assessment.

We commit to acknowledging receipt within 48 business hours and deploying fixes promptly.
