{{ _("Comment scanner un livre") }}

1

{{ _("Retournez le livre") }}

{{ _("Le code-barres ISBN se trouve au verso (4ème de couverture), généralement en bas à droite.") }}

2

{{ _("Vérifiez que c'est bien un ISBN") }}

{{ _("Le code doit commencer par 978 ou 979 et faire 13 chiffres. Les autres codes-barres (prix, éditeur) ne fonctionnent pas.") }}

3

{{ _("Positionnez votre caméra") }}

{{ _("Maintenez l'appareil à 15-20 cm du code, de face, bien aligné. Le scan se déclenche automatiquement en quelques secondes.") }}

{{ _("Astuces pour un meilleur scan :") }}
  • {{ _("Essayez le zoom 1x si le scan ne fonctionne pas en ultra-large (.5x)") }}
  • {{ _("Activez la torche si la pièce est sombre") }}
  • {{ _("Évitez les reflets : posez le livre à plat et filmez de dessus") }}

{{ _("Dépannage — La caméra ne s'ouvre pas") }}

{{ _('Erreur : "Impossible d\'accéder à la caméra"') }}

  1. {{ _("Autorisez la caméra dans les paramètres de votre navigateur (icône cadenas dans la barre d'adresse)") }}
  2. {{ _("Vérifiez qu'aucune autre application n'utilise la caméra en même temps") }}
  3. {{ _("Rechargez la page et autorisez lorsque le navigateur le demande") }}
  4. {{ _("Sur iOS : utilisez Safari — Chrome sur iOS ne supporte pas toujours l'accès caméra") }}
